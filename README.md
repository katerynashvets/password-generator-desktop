# Password Generator

A desktop application for generating secure passwords, built with Next.js and Electron.

- [Features](#features)
- [Installation](#installation)
- [Tech Stack](#tech-stack)

## About

Password Generator is a desktop app that helps you create strong and secure passwords with customizable settings. All settings are saved locally on your machine.

---

## Features

- Generate secure passwords
- Customize password length and character types
- Settings saved locally
- Dark / Light mode

---

## Installation

1. Go to [Releases](../../releases)
2. Download `Password Generator Setup 1.0.0.exe`
3. Run the installer
4. Launch the app

> **Requirements:** Windows 10 or higher

## Development

### Prerequisites

- Node.js 18+
- npm

### Setup

```bash
# Install dependencies
npm install

# Start Next.js dev server
npm run dev

# In a second terminal — start Electron
cd electron
npm install
npm start
```
